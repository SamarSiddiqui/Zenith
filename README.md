# Zenith (زينيث) - Mindful Habit Tracker

**Zenith** is a mindful habit planner built to help you build focus, maintain streaks, and achieve your goals with a serene, distraction-free interface. 

## Meaning of Zenith (زينيث)
The word **Zenith** refers to the time at which something is most powerful or successful; the highest point or peak. In Arabic, it is written as **زينيث**. This application is designed to help you reach your personal zenith through consistent, daily mindful habits.

## Getting Started

This is a [Next.js](https://nextjs.org) project bootstrapped with [`create-next-app`](https://github.com/vercel/next.js/tree/canary/packages/create-next-app).

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

This project is built using:
- **Next.js** (App Router)
- **Tailwind CSS v4**
- **Framer Motion** for animations
- **Lucide React** for iconography
