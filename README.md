# Zenith - Mindful Habit Tracker

**Zenith** is a mindful habit planner built to help you build focus, maintain streaks, and achieve your goals with a serene, distraction-free interface. 

## Meaning of Zenith (زينيث)
The word **Zenith** refers to the time at which something is most powerful or successful; the highest point or peak. In Arabic, it is written as **زينيث**. This application is designed to help you reach your personal zenith through consistent, daily mindful habits.
